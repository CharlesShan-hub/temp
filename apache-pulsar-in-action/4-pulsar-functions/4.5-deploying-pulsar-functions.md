## 4.5 Deploying Pulsar functions

After you have compiled and tested your Pulsar functions, you will eventually want to deploy them to a production cluster. The pulsar-admin functions command-line tool was designed specifically for this purpose, and it allows you to provide several configuration properties for the functions, including tenant, namespace, input, and output topics. In this section I will walk through the process of configuring and deploying a Pulsar function using this tool.
